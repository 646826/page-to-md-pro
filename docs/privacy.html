Page to Markdown Pro

Privacy Policy

Last updated: July 19, 2026

Data processing

The extension reads the active page or current selection only after an explicit toolbar, shortcut, or context-menu action. Page content, selections, metadata, and generated Markdown are processed locally in the browser and are not sent to developer-controlled servers.

Storage

Only user preferences are stored. The extension normally uses chrome.storage.sync and falls back to local extension storage when sync storage is unavailable. Captured page content and generated Markdown are not stored in extension storage.

Network and analytics

The extension contains no telemetry, analytics, advertising, accounts, cloud processing, or remote executable code. A generated Markdown file may contain links already present on the source page; the extension does not fetch those linked resources while generating the file.

Permissions

activeTab, scripting, downloads, contextMenus, offscreen, and storage are used only for page-to-Markdown export. The extension requests no host permissions.
