# Page to Markdown Pro 0.2.2

Released on 2026-08-02.

## What changed

- Ordered lists now preserve an explicit `start="0"` value instead of replacing it with `1`.
- Negative ordered-list starts remain negative and continue in the correct direction.
- `<ol reversed>` starts from the number of direct list items unless a valid explicit `start` is present.
- A direct `<li value="…">` resets the current counter, and following items continue from that value in the list direction.
- Continuation lines and nested lists use indentation derived from the actual marker width, so content under markers such as `10.` remains valid Markdown.
- A real Chromium fixture covers zero, negative, reversed, reset, multi-digit, multiline, and nested-list behavior.

## Compatibility and security

- No extension permissions, host permissions, runtime dependencies, telemetry, or remote executable code were added.
- The minimum supported Chrome version remains 109.
- Existing task-list rendering and unordered-list behavior remain covered by the complete regression suite.
- Automated delivery remains `UPLOAD_ONLY`: the package is uploaded to Chrome Web Store but is not submitted for publication automatically.

## Verification gates

The release candidate must pass all 36 Node tests, all eleven Chromium fixtures, the aggregate `npm test` command, deterministic ZIP construction, and exact 18-file package allowlist validation before merge. The main-branch release workflow repeats the complete verification before Chrome Web Store upload and GitHub Release creation.
