# Page to Markdown Pro 0.3.0

## What's new
- Export selected text from an accessible embedded frame using its selection context menu. The exporter targets the originating frame instead of the main page.
- Prevent a stalled script initialization from keeping a tab's export operation permanently busy.
- Preserve newly saved preferences when synchronization fails, without silently reverting to older synchronized values.
- Read local and synchronized settings in parallel.
- Additional regression coverage for frame routing, recovery and preference persistence.

## Что нового
- Добавлен экспорт выделенного текста из доступного встроенного фрейма через контекстное меню.
- Зависшая инициализация больше не блокирует повторный экспорт в той же вкладке.
- Исправлен откат настроек к старым значениям при ошибке синхронизации.
- Настройки из двух хранилищ читаются параллельно.
- Добавлены проверки восстановления после ошибок и корректного выбора фрейма.
