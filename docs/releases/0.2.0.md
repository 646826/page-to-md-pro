# Page to Markdown Pro 0.2.0

Version 0.2.0 is a reliability release for modern, generic web pages.

## User-visible improvements

- Better extraction from documentation, articles, wikis, and component-based pages.
- Open Shadow DOM and slotted content are included when available.
- Task-list checkboxes become `- [x]` and `- [ ]` Markdown.
- JSON-LD can recover article title, author, description, and publication date.
- Lazy images, placeholder image sources, and media links are normalized to meaningful absolute URLs.
- Large downloads no longer lose their Blob URL before Chrome finishes reading it.
- Repeated clicks and transient retries on one tab no longer duplicate the capture operation.
- Stored settings are normalized, sync storage has a local fallback, and stale fallback values no longer override readable sync settings.
- Release ZIPs are reproducible and validated against an exact 15-file runtime allowlist.
- Image-only selections are preserved instead of falling back to the whole page.
- Open Shadow DOM follows the composed tree, excluding hidden light-DOM nodes and duplicate slot content.
- Unsafe active links and literal HTML are rendered as inert text; complex HTML tables are sanitized.
- Status badges are ordered so delayed updates cannot hide a successful or newer capture state.

## Compatibility

Chrome remains the release target. The same unpacked package is exercised in Chromium and is expected to work in Chromium-derived browsers that support the required Manifest V3 APIs. There are no separate Edge, Brave, or Vivaldi builds.

Minimum Chrome version: 109. The options UI includes non-`color-mix()` fallbacks for that baseline.

## Privacy

The extension still works locally, adds no host permissions, and does not send page contents, selections, generated Markdown, or usage data to developer-controlled servers.

## Delivery

The verified ZIP is uploaded to the Chrome Web Store using `UPLOAD_ONLY`. This places the package in the developer dashboard but does not submit it for review or publication. The GitHub Release is created only after the upload succeeds.
