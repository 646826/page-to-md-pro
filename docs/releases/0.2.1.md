# Page to Markdown Pro 0.2.1

Released on 2026-08-02.

## What changed

- HTML `<br>` elements now render as valid `<br>` Markdown followed by a newline.
- Code-block containers reached through inline or custom-element flow no longer receive a stray `l` prefix.
- A real Chromium regression fixture exercises both paths and runs as a focused CI step as well as part of the aggregate suite.
- The existing published-release verifier now has its own focused CI step for clearer failures.
- Its test fixture now derives the version and tag from `manifest.json`, avoiding hard-coded release numbers in future version bumps.

## Compatibility and security

- No extension permissions, host permissions, runtime dependencies, telemetry, or remote executable code were added.
- The minimum supported Chrome version remains 109.
- Automated delivery remains `UPLOAD_ONLY`: the package is uploaded to Chrome Web Store but is not submitted for publication automatically.

## Verification gates

The release candidate must pass all 36 Node tests, all ten Chromium fixtures, `npm test`, deterministic ZIP construction, and exact release-package allowlist validation before merge. The main-branch release workflow repeats the full verification before store upload and GitHub Release creation.
