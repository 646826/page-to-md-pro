# Page to Markdown Pro 0.3.1

## What's new
- Table captions, units, explanations and their safe links are preserved in Markdown exports.
- Caption-only tables retain their text; HTML table mode does not duplicate captions.
- Inline code preserves significant spaces, tabs and literal backticks instead of collapsing them.
- Large code snippets with many backtick sequences no longer fail at the JavaScript argument-count limit.

## Что нового
- При экспорте таблиц сохраняются подписи, единицы измерения, пояснения и ссылки.
- Сохраняется текст таблиц без строк; подписи в HTML-режиме не дублируются.
- Строчный код сохраняет значимые пробелы, табуляцию и обратные кавычки.
- Устранён сбой экспорта больших фрагментов кода с многочисленными последовательностями обратных кавычек.

## Release scope
Includes merged PRs #27 and #28 and all changes from 0.3.0. Existing permissions, dependencies, extraction modes and settings are unchanged.
The combined release is subject to the complete Node/Chromium fixture and package verification. No measured whole-export speedup or universal website fidelity is claimed.
Normal Store review is required. Existing pending submissions are not cancelled. The package API does not edit the Store listing description; these English/Russian notes are ready for that separate step.
