Page to Markdown Pro

Support

Report bugs, extraction regressions, and feature requests in the GitHub issue tracker.

Include in a report

  • A public page URL or a minimal HTML fixture
  • Browser and extension versions
  • Automatic, main, full-page, or selection mode
  • Expected Markdown and the relevant actual excerpt
  • Any stable service-worker or page error code
  • Whether the page was reloaded after the extension was updated

Remove private information before attaching generated Markdown. Closed shadow roots, cross-origin frames, canvas-only content, virtualized rows not currently rendered, and content never exposed in the active DOM cannot be extracted generically.
